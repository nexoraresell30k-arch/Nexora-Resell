NEXORA RESELL — CONFIGURATION DU SITE

CONTACT
Le bouton de contact ouvre votre application e-mail vers nexoraresell.30k@gmail.com. Il fonctionne sans serveur, si une application e-mail est configurée.

COMPTES UTILISATEURS (connexion réelle, pas une simulation)
1. Avec un parent responsable, créer un projet gratuit sur https://supabase.com/
2. Dans Authentication > Providers, activer Email.
3. Dans Authentication > URL Configuration, indiquer l’URL publique du site et ses URL de redirection autorisées.
4. Dans Project Settings > API (ou API Keys), copier l’URL du projet et la clé publique anon / publishable.
5. Ouvir index.html et remplir SUPABASE_URL et SUPABASE_ANON_KEY. Ne jamais mettre la clé secrète service_role dans le HTML.
6. Héberger le dossier sur un site HTTPS (par exemple GitHub Pages).
7. Tester la création de compte, la confirmation e-mail, la connexion et la déconnexion.
8. Avant toute collecte réelle de données personnelles, prévoir une politique de confidentialité, les informations du responsable du site, la durée de conservation et une procédure de suppression des comptes. Vérifier les conditions d’âge de l’hébergeur et de Supabase.

IMPORTANT
Sans configuration Supabase, le bouton d’inscription est visible mais ne crée pas de compte. Ne collectez pas de mots de passe dans des fichiers locaux ou par e-mail. Le site reste une vitrine sans achat ni paiement.
